Connect your Bipkin

Use Chrome or Edge on a computer. Connect the device with a data-capable USB cable, select its port, then on the device tap SET UP WI-FI and then USB Web Flasher Setup to open the 60-second window. Send the network within 60 seconds.

Close any serial monitor or device mirror using the same port first. WiFi credentials stay on this device. Internet time verification is required before care and rewards unlock.

An empty password is only for an open network. Otherwise enter 8–63 UTF-8 bytes.

Select a USB device to start.
