Bipkins™ Official Firmware

Bipkins™ Web Flasher

Flash Bipkins companion firmware directly to your ESP32 CYD board via Web Serial.

Web Serial Unavailable
Web Serial requires Chrome, Edge, or Opera on desktop over HTTPS. Safari and Firefox do not support Web Serial.
HTTPS Required
Web Serial is only allowed over HTTPS or on localhost. Ensure you are accessing via https://.
📋 Quick Installation Guide:
1 Connect your ESP32 CYD board to your computer with a USB-C data cable.
2 Click Connect & Install Bipkins™ above and select your device's USB COM / Serial port (CH340 / CP2102).
3 Follow the installer prompt. To preserve your pet's name and NVS state during an upgrade, do not check "Erase device".
